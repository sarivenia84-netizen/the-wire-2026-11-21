# The Wire — 21 November 2026

A one-page visual summary of world news for Saturday, 21 November 2026, built as a
single deterministic HTML/CSS composition (no network assets) and rendered to PNG at
1600×2000 @2x.

## How it was made
- `index.html` — the whole composition. System serif/sans fonts only, no external
  fonts, images or scripts, so the render is byte-stable on any machine.
- Rendered with headless Chrome via CDP (`Emulation.setDeviceMetricsOverride`
  1600×2000, deviceScaleFactor 2) and captured to `news-20261121.png`.
